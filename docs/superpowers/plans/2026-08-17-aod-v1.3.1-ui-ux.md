# Lunaa Adaptive AOD v1.3.1 UI/UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the v1.3 settings UI around Automatic/Manual modes, brighter useful presets, advanced disclosure, and Android 15/16 safe insets.

**Architecture:** Keep the existing platform-Views single-activity architecture and settings/runtime interfaces. Limit behavior changes to built-in preset values and UI presentation. Add window-inset handling directly with platform APIs so no AndroidX dependency is required.

**Tech Stack:** Java 17, Android platform Views, targetSdk 36, legacy Xposed/Vector settings transport.

## Global Constraints
- Keep module package `dev.lunaa.aod`.
- Keep Xposed scope/runtime behavior unchanged.
- Do not add System Framework hooks or UDFPS hooks.
- No AndroidX or Material dependency.
- Minimum interactive target 48dp.
- Respect status/navigation/IME insets on Android 15/16.
